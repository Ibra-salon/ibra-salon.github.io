# Ibra-salon · Журнал мастера

Журнал визитов, записей и смен парикмахера с аналитикой. Работает в телефоне как приложение, без аккаунтов, входа и серверов. Все данные хранятся только в телефоне владельца, копия сохраняется в Excel.

**Адрес:** https://ibra-salon.github.io/

## Как начать

1. Открыть адрес в Safari (iPhone) или Chrome (Android).
2. Добавить на экран «Домой»: на iPhone «Поделиться» → «На экран Домой».
3. Дальше открывать журнал только с этой иконки. На iPhone у неё своя память, отдельная от Safari.

## Где данные и как не потерять

- Данные лежат в памяти телефона (IndexedDB браузера). В интернет они не уходят, никто, кроме владельца, их не видит.
- **Копия:** вкладка «Ещё» → «Сохранить копию в Excel». На телефоне откроется меню «Поделиться»: удобно отправить файл себе в Telegram, в «Избранное». Если копию не сохраняли 7 дней, журнал напоминает на главном экране.
- **Новый телефон или сброс:** открыть сайт, добавить на экран «Домой», «Ещё» → «Восстановить из файла» → выбрать последний Excel.
- Удаление иконки с экрана «Домой» на iPhone стирает и её данные. Перед этим сохранить копию.

## Что в Excel

Листы: Визиты, Позиции (услуги внутри визитов), Клиенты, Смены, Услуги (прайс), Настройки. Столбцы `id` нужны для восстановления, их лучше не трогать. Файл можно открыть в Excel или Numbers либо отдать ChatGPT или Claude с вопросом вроде «что с моими клиентами за месяц».

## Как устроено

Статический сайт на GitHub Pages: HTML, CSS и JavaScript без сборки и фреймворков. Без интернета работает через service worker (`sw.js`). Подробности для разработки в `CLAUDE.md`.

## Локальный запуск

```
python3 -m http.server 8765
```
и открыть http://localhost:8765/
